Quiz App
A simple Quiz Application developed using Java and Maven.
The application allows users to participate in quizzes and answer multiple-choice questions.
 About the Project
The Quiz App is a Java-based application developed to provide a simple and interactive way to conduct quizzes.
The project demonstrates core Java programming concepts, application structure, and Maven-based project management.
 Features
•	 Multiple-choice quiz questions
•	 Answer selection and validation
•	 Quiz score calculation
•	 Interactive quiz flow
•	 Simple and user-friendly application
•	 Maven-based project structure
 Technologies Used
•	Java
•	Maven
•	Eclipse IDE / Java IDE

 Getting Started
Prerequisites
Make sure you have the following installed:
•	Java JDK
•	Maven
•	Eclipse IDE or any Java-compatible IDE
Clone the Repository
git clone https://github.com/Sharaal2703/quiz-app.git
Navigate to the Project
cd quiz-app
Build the Project
mvn clean install
Run the Application
Open the project in Eclipse or your preferred Java IDE and run the main Java class.
 How It Works
1.	Start the Quiz Application.
2.	The application displays quiz questions.
3.	Select an answer for each question.
4.	The selected answer is evaluated.
5.	Continue until all questions are completed.
6.	The final score is displayed.
